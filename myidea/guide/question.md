# 常见问题

因 MyIdea 尚未采购微软、苹果官方代码签名证书，因此软件安装过程中系统可能弹出安全风险提示。在此我们郑重承诺：

1. 用户的任何操作数据都保存在本地，不会被联网上传；
2. 软件不包含任何广告、推广、数据收集等功能；
3. 软件的安装包和更新包均经过我们团队的严格检查，确保不包含任何恶意代码；
4. 我们欢迎用户对软件进行安全审计，并将结果公开以供监督；
5. 如果您在安装或使用过程中遇到任何安全问题，请第一时间联系我们，我们将积极配合解决，并向用户通报情况；

感谢您的理解与支持，我们将持续努力为您提供安全、可靠的产品体验。

## MacOS 下打开 MyIdea 时提示“已损坏无法打开”

1. 在终端执行以下命令:

`sudo xattr -rd com.apple.quarantine /Applications/MyIdea.app`

2. 根据提示输入开机密码；
3. 再次打开 MyIdea 即可。

## Windows 下安装时提示“运行此应用可能会使你的电脑处于危险之中”

点击 “运行” 即可。
